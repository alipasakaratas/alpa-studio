---
description: Validates Unity builds on available iOS simulators, Android emulators, and connected physical devices without fabricating capability.
---

Run `alpa doctor --project .` first. Build only when the exact Unity version, platform module, disk space, and project lock state are verified. Record device model/runtime, build/commit, commands, logs, screenshots/video, performance observations, and result. A configured emulator that was not launched is not a passed test; a physical device not connected is unavailable.
