# Alpa Studio — {{PROFILE_NAME}}

Project-scoped installation of Alpa Studio {{FRAMEWORK_VERSION}}. It does not modify global Claude Code, Unity, Xcode, Android, Blender, or shell configuration.

## Start

1. Run `alpa doctor --project .` and keep unavailable capabilities visible.
2. Invoke `/studio-start` in Claude Code.
3. Approve the Game Bible, Art Bible, one of three concepts, and Master Asset before production.
4. Run independent staged QA; the internal target is 95/100.

State is stored in `.alpa-studio/`. Owner approvals are explicit records, not inferred from chat silence.
