# Security, rights, and child compliance gate

- No secrets, signing files, real identifiers, personal data, or credentials in Git.
- Every external asset has author/source, license text, version/date, permitted use, and modification record.
- Similarity review covers characters, icons, screenshots, store identity, music, voice, and recognizable competitor trade dress.
- Collect no child data by default. Parental gates, age handling, analytics/ads, consent, account, chat, location, camera, microphone, and external links need jurisdiction-specific review and owner approval.
- This framework provides engineering gates, not legal advice. Current store and legal rules require fresh primary-source verification before release.
