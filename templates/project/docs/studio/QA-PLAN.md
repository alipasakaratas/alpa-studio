# Independent staged QA

Internal target: **95/100**. A score is evidence, not permission to violate approved decisions.

Weights: art fidelity 25%, composition 15%, readability 15%, interaction 15%, performance 15%, accessibility 15%.

Stages: asset technical QA → isolated asset visual QA → Unity integration QA → scene/screenshot QA → interaction/video QA → performance QA → device matrix → independent final review.

Each review records reviewer identity, build/commit, device, reference, images/video/logs, defects, score, and retest. A producer or implementer cannot provide the final independent review of their own work.
